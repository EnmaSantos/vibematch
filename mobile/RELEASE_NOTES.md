## Android preview

Download **VibeMatch-Android.apk** below and install it on an Android 8.0 (API 26) or newer device. If Android asks, allow your browser or file manager to install this APK. The APK is signed so future VibeMatch releases can update this installation.

Tap **Explore the demo** to try the native movie-picking flow without an account. The sample partner is simulated, and demo changes stay on your device. Live sign-in is disabled in this first downloadable build while the mobile API deployment and device testing are completed.

This is a preview of the Kotlin/Jetpack Compose app. It includes the vibe check, timed swipe rounds, movie details, shared match results, and saved demo sessions. Native sign-up, OAuth, and other web features are still in progress. There is no installable iOS build in this release.

You can compare the downloaded file with **SHA256SUMS.txt** if you want to verify its integrity. Please report problems in the repository's Issues tab and include your Android version and the steps to reproduce them.
