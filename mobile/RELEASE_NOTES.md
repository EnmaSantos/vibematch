## VibeMatch Android preview v0.2.1

Download **VibeMatch-Android.apk** below and install it on an Android 8.0 (API 26) or newer device. If Android asks, allow your browser or file manager to install the APK. This release uses the same signing key as v0.1.0, so it can update an existing installation.

The Kotlin app now connects to the live VibeMatch service by default. You can sign in with a verified email/password account or choose **Continue with Google**. After sign-in, create or join a room with another person, make movie choices, and view shared matches. **Explore the demo** remains available offline without an account; its sample partner is simulated and demo changes stay on your device.

Google sign-in opens a browser and returns to the app. If the browser does not return automatically, reopen VibeMatch and try again. This is still a preview: live matching and the full sign-in flow have not yet been verified on two physical devices. There is no installable iOS build in this release, though the iOS project supports the same account flow in Xcode.

You can compare the downloaded file with **SHA256SUMS.txt** if you want to verify its integrity. Please report problems in the repository's Issues tab and include your Android version and the steps to reproduce them.
